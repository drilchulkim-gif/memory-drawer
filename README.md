# 🗂️ 기억의 서랍

**말하고, 남기고, 다시 찾는 개인 기억 앱**  
Android용 설치 앱 · 현재 버전 **V1.3**

[![APK 내려받기](https://img.shields.io/badge/APK-기억의%20서랍%20내려받기-2d7f73?style=for-the-badge&logo=android&logoColor=white)](https://github.com/drilchulkim-gif/memory-drawer/releases/latest/download/memory-drawer.apk)

> 위의 **APK 내려받기** 버튼을 누르면 최신 설치 파일을 받을 수 있습니다.

## 이런 앱입니다

- 🎙️ **말로 입력** — 휴대폰의 한국어 음성인식으로 기억을 글로 남깁니다.
- 🔎 **말로 검색** — 떠오르는 단어나 문장으로 저장한 기억을 찾습니다.
- 💾 **휴대폰에 저장** — 기록은 사용자의 휴대폰 안에 보관됩니다.
- 📦 **백업·복원** — JSON 파일로 기억을 백업하고 다시 불러올 수 있습니다.
- 📵 **기본 기능은 오프라인 사용 가능** — 음성인식은 휴대폰 설정에 따라 인터넷 연결이 필요할 수 있습니다.

## 설치 방법

1. 위의 **APK 내려받기** 버튼을 누릅니다.
2. 내려받은 `memory-drawer.apk` 파일을 엽니다.
3. 연결 앱을 묻는 경우 **패키지 설치 프로그램**을 선택합니다.
4. 처음 설치할 때 **이 출처의 앱 설치 허용**이 나오면 한 번 허용합니다.
5. **설치**를 누릅니다.
6. 설치가 끝나면 앱 목록의 **기억의 서랍**을 열고 사용합니다.

## 처음 사용할 때

**말로 입력** 또는 **말로 검색**을 누르면 휴대폰의 음성인식 화면이 열립니다. 한국어로 말하면 인식된 내용이 앱에 입력됩니다.

## 개인정보와 저장 방식

이 앱은 별도의 회원가입을 요구하지 않습니다. 사용자가 작성한 기억은 기본적으로 해당 휴대폰의 앱 저장공간에 저장됩니다. 앱을 삭제하기 전에는 필요할 때 **백업** 기능으로 기록을 따로 보관하는 것을 권장합니다.

## 주의

이 APK는 Google Play가 아니라 직접 배포하는 설치 파일이므로 Android가 처음 한 번 설치 허용 여부를 확인할 수 있습니다. 파일은 이 공식 GitHub 저장소의 **Releases**에서만 내려받는 것을 권장합니다.
