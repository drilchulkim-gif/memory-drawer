# 기억의 서랍 Android V1.3

목표: 사용자가 APK를 내려받아 설치하고 홈 화면의 아이콘으로 바로 실행하는 설치형 버전.

## V1.3 핵심
- 휴대폰 기본 한국어 음성인식(RecognizerIntent)을 직접 호출
- 브라우저 Web Speech API 의존성 제거
- 음성 결과가 기록 입력칸 또는 검색 입력칸에 자동 입력
- IndexedDB 기반 기억 저장
- JSON 백업을 `다운로드/기억의서랍` 폴더에 저장
- 백업 복원을 위한 Android 파일 선택기 연결
- 인터넷 연결 없이도 앱 UI와 저장된 기억 사용 가능
  (단, 휴대폰 음성인식 서비스 자체는 기기 설정에 따라 인터넷을 요구할 수 있음)

## APK 자동 빌드
main 브랜치에 코드가 올라오면 GitHub Actions가 APK를 자동 생성합니다.

## 설치
APK를 Android 휴대폰에 다운로드 → 파일 열기 → '이 출처의 앱 허용'이 필요한 경우 한 번 허용 → 설치.
설치 후 앱 목록/홈 화면에 `기억의 서랍`이 표시됩니다.
