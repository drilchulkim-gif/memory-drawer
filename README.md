## V2.0의 기록 구조

- 👤 **개인 기록실** — 나의 경험, 생각, 일상, 일과 배움
- 👪 **가족 기록실** — 부모, 배우자, 자녀, 손주, 가족사
- 🌏 **사회 기록실** — 사회·문화·시대 변화에 대한 기억과 생각
- 📅 **날짜별 기록** — 실제 사건 날짜를 지정하고 날짜별로 묶어 보기
- 🏷️ **꼭지별 기록** — 각 기록을 제목과 본문으로 분리해 독립된 꼭지로 관리
- 🔎 **검색·월별 보기·정렬** — 제목/내용 검색, 월별 필터, 최신/오래된 순 정렬
- ✏️ **수정·이동·삭제** — 꼭지를 고치거나 다른 기록실로 옮길 수 있음
- 🎙️ **말로 입력·검색** — 휴대폰의 한국어 음성인식 사용
- 📦 **전체 백업·복원** — 세 기록실을 JSON 파일 하나로 백업
- 🔁 **기존 V1.3 기록 보존** — 기존 기록은 자동으로 개인 기록실에 이전됨

## 설치 방법

1. 위의 **APK 내려받기** 버튼을 누릅니다.
2. 내려받은 `memory-drawer.apk` 파일을 엽니다.
3. 연결 앱을 묻는 경우 **패키지 설치 프로그램**을 선택합니다.
4. 처음 설치할 때 **이 출처의 앱 설치 허용**이 나오면 한 번 허용합니다.
5. **설치**를 누릅니다.
6. 설치가 끝나면 앱 목록의 **기억의 서랍**을 열고 사용합니다.

## 개인정보와 저장 방식

회원가입은 필요 없습니다. 기록은 기본적으로 해당 휴대폰의 앱 저장공간에 저장됩니다. 앱을 삭제하기 전에는 **전체 백업**으로 기록을 따로 보관하는 것을 권장합니다.
